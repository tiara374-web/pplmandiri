MISI 1 • SPOT THE PROBLEM

Ada yang aneh dari program ini?

    #include <iostream>
    using namespace std;

    int main() {
        cout << "Hello";
    }

    return 0;

MISI 2 • ANATOMI PROGRAM

Kode punya tempat. Klik bagian untuk melihat fungsinya.

Penjelasan

Klik salah satu baris di sebelah kiri.

Peta singkat:

Bagian atas → persiapan program

main() → rumah utama program

Di dalam { } → tempat kita bekerja

📒 CATAT DI BUKU — “Peta Program C++”

  1. #include <iostream> = menyiapkan input/output.
  2. using namespace std; = membantu penulisan cin dan cout.
  3. int main() = program utama.
  4. Isi program ditulis di dalam { }.
  5. Urutan sederhana: Deklarasi → Input → Proses/Kondisi → Output.

MISI 6 • BUG HUNT

Klik semua baris yang bermasalah

Ada 4 baris bermasalah.

Kode setelah diperbaiki

#include <iostream>
using namespace std;

int main() {
    int umur;
    cin >> umur;

    if (umur >= 17) {
        cout << "Boleh membuat SIM";
    } else {
        cout << "Belum cukup umur";
    }

    return 0;
}

📒 TUGAS INDIVIDU DI BUKU — BUILD

  1. Tulis: variabel, tipe data, input, kondisi, output TRUE, output FALSE.
  2. Setelah benar, tulis ulang kodenya di buku tanpa menyalin dari teman.
  3. Lingkari int main() dan beri panah ke area tempat kalian menulis kode.
MISSION COMPLETE

Checklist sebelum menekan RUN

✓ Variabel sudah dideklarasikan
✓ Perintah penting memiliki ;
✓ cin memakai >>
✓ cout memakai <<
✓ kondisi if memakai ( )
✓ { } lengkap
✓ kode ditulis di dalam main()
✓ int main() tidak ditulis dua kali

Jangan hafalkan seluruh kode. Pahami strukturnya.
